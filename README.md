# A2 German → English Anki Deck

1214 flashcards for German A2 vocabulary with English translations.

## Download

📥 **[Download from Releases](https://github.com/oprobiu/DataDAF2/releases)** — import directly into [Anki](https://apps.ankiweb.net/)

Also available: [German → Romanian version](https://github.com/oprobiu/DataDAF2/releases/tag/v1.0.0-ro)

## What's in the deck

- 1214 cards (2428 with reverse), based on Goethe A2 wordlist
- German word + up to 4 example sentences, with English translations
- TTS audio for every word and sentence (gTTS, de-DE)
- Color-coded articles: der / die / das
- Verb forms: infinitiv, Präteritum, Partizip
- Tags: NOUN, VERB, ADJ, ADV, PREP, CONJ, PRON, PHRASE, NUM, OTHER

## Build from source

Requires Python 3.8+ and [AFAS](https://github.com/oprobiu/AFAS).

```bash
make bootstrap
make validate
make build
```
